# 德州扑克游戏 - 玩家指南

---

## 🎮 游戏介绍

这是一款完整的离线德州扑克游戏，支持单人对抗 5-7 个不同风格的 NPC 玩家。游戏采用标准德州扑克规则，包含完整的游戏流程、智能 NPC AI、精美的 UI 界面和流畅的游戏体验。

### ✨ 核心特性

- **完整规则实现**：遵循标准德州扑克规则，包含翻牌前/翻牌/转牌/河牌/摊牌/结算全流程
- **4种 NPC 风格**：
  - 🟢 保守型：只玩强牌，极少诈唬，高弃牌率
  - 🔴 激进型：频繁加注和诈唬，进攻性强
  - 🟡 平衡型：根据牌力和位置灵活调整策略
  - 🟣 疯狂型：极度激进，几乎不弃牌，经常 All-in
- **全自动游戏流程**：NPC 自动思考和行动，无需人工干预
- **精美 UI**：操作日志、实时底池显示、结算弹窗、思考提示
- **多局连续游戏**：筹码自动累计，支持连续多手牌

```bash
npm run build
```

## 📖 游戏规则

### 基础规则
- 玩家数：2-8人（本游戏支持 1 人类 + 1-7 NPC）
- 牌组：52张牌，无大小王
- 目标：用 2 张底牌 + 5 张公共牌组合出最大的 5 张牌型，赢得底池

### 牌型大小（从大到小）
1. **皇家同花顺**：A-K-Q-J-10 同花色
2. **同花顺**：五张连续同花色
3. **四条**：四张相同点数
4. **葫芦**：三条 + 一对
5. **同花**：五张同花色
6. **顺子**：五张连续点数
7. **三条**：三张相同点数
8. **两对**：两个不同对子
9. **一对**：两张相同点数
10. **高牌**：单张最大牌

### 游戏流程
1. **盲注**：小盲和大盲位强制下注
2. **翻牌前**：每人发 2 张底牌，从大盲后第一位开始行动
3. **翻牌**：发 3 张公共牌，从小盲位开始行动
4. **转牌**：发第 4 张公共牌，行动顺序同上
5. **河牌**：发第 5 张公共牌，行动顺序同上
6. **摊牌**：未弃牌玩家比较手牌大小
7. **结算**：赢家赢得底池，筹码自动分配

### 行动说明
- **弃牌（Fold）**：放弃本局，不再参与
- **过牌（Check）**：不下注，将行动权传给下一位（仅当当前无未匹配注时可使用）
- **跟注（Call）**：跟上当前最高下注额
- **加注（Raise）**：增加下注额
- **All-in**：投入全部剩余筹码

## 🎯 游戏操作

### 大厅设置
1. 输入你的昵称
2. 选择玩家人数（2-8人）
3. 设置大盲注金额（10/20/50/100）
4. 调整买入筹码（20x-200x 大盲）
5. 点击"开始游戏"

### 游戏中操作
- 轮到你行动时，操作按钮会自动点亮
- 点击对应按钮执行行动
- 加注时可以使用滑块选择金额，或点击快捷按钮
- 左侧边栏查看行动历史
- 顶部显示当前阶段和手牌数

### 结算
- 每手牌结束后自动弹出结算窗口
- 查看赢家信息和所有玩家筹码变化
- 点击"下一手"开始新一局
- 玩家筹码为 0 时会被淘汰

## 🤖 NPC 行为说明

| NPC 类型 | 风格特点 | 应对策略 |
|---------|----------|----------|
| 保守型 | 只玩 AA/KK/AK 等强牌，弃牌率高 | 遇到其加注时要谨慎，没有强牌可以弃牌 |
| 激进型 | 频繁加注和诈唬，经常偷盲 | 可以用中等牌力跟注，抓其诈唬 |
| 平衡型 | 打法均衡，难以预测 | 正常打法，根据牌力决策 |
| 疯狂型 | 几乎不弃牌，经常 All-in | 只要有不错的牌就可以跟注或加注 |

## 🔧 技术说明

### 技术栈
- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite 8
- **状态管理**：Zustand + Immer
- **样式框架**：TailwindCSS v4
- **路由**：react-router-dom v7
- **测试框架**：Vitest

### 项目结构
```
src/
├── engine/          # 游戏核心引擎（纯函数，无 UI 依赖）
├── ai/             # NPC AI 系统
├── components/     # UI 组件
├── store/          # Zustand 状态管理
├── hooks/          # 自定义 Hooks
├── router/         # 路由配置
└── utils/          # 工具函数
```
